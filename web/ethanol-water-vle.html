參數與數據來源

NRTL（Aspen/DDB）：a12 = −0.8009，b12 = 246.18 K，a21 = 3.4578，b21 = −586.0809 K，α = 0.3。Aspen Plus 資料庫以 Dortmund Data Bank 迴歸之值，表列於 Beneke 等，Understanding Distillation Using Column Profile Maps（Wiley, 2013）附錄 B。

本研究迴歸：aij = 0，b12 = −37.54 K，b21 = 640.64 K（對 Kamihama 等數據加權最小平方）。Van Laar：A12 = 1.700，A21 = 0.953（同上迴歸）。課程範例：課程講義程式中標示為示意用的值。

蒸氣壓：報告版＝乙醇 NIST WebBook（Ambrose & Sprake 1970）、水 IAPWS-IF97 飽和線；repo 版＝常見 mmHg／°C Antoine 表列值（乙醇適用至 80 °C）。

實驗數據：N. Kamihama 等，J. Chem. Eng. Data 57 (2012) 339–344，經 NIST TRC ThermoML 收錄；ΔHmix 25 °C 極小值：Larkin (1975)、Ott 等 (1986)。

計算：每個液相組成以 Illinois 法解泡點溫度；過剩焓由 Gibbs–Helmholtz 關係對 GE/RT 數值微分；McCabe–Thiele 採恆莫耳溢流、飽和液體進料、全凝器，進料 100 kmol/h，再沸器負荷以水的汽化熱 40.65 kJ/mol 估算。程式與報告：github.com/Shuruyue/Ethanol-Water-VLE（report-2026-revision）。
